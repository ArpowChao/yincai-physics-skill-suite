# 高中物理素養題命題

## Overview

以三面向八準則設計必須使用情境資訊、完成物理推理並把結果用於決策、評估或解釋的題目。自評不是自動給高分；證據不足就降分或重寫。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/literacy-eight-criteria.json`
- `../../../data/misconceptions/starter.json`

## Inputs

必需：

- 專案學習節點碼與單元名稱
- 評量目標與題型
- 學生課程層級

建議：

- 真實資料來源、圖表或裝置規格
- 預計作答時間與計算工具
- 指定認知歷程
- 既有題目或教材包目標

## Workflow

1. 解析官方父碼，選定 1-1 的對應內容與不能越過的教學邊界。
2. 先寫評量主張：「學生要用哪些證據展現什麼推理」。
3. 選真實問題，再選情境；不要先寫故事再硬塞公式。
4. 建立必要資料與表徵。每個數值註明來源、合理簡化或「教學用假設」。
5. 完成題目與完整解題，檢查條件充分、正解唯一、單位與有效位數。
6. 設計誘答：每個錯誤選項對應可解釋的迷思或推理分岔，不能只是亂數。
7. 做捷徑測試、刪除測試、表徵必要性測試與範圍測試。
8. 逐項依 1–4 分規準評分，引用題幹中的可指認證據。任何 gate 未過先改題再重評。
9. 再交由 `physics-question-qa-checker` 做獨立物理與數值雙檢。

## Output contract

輸出：

1. **命題藍圖**：官方碼、評量主張、認知歷程、情境用途、預計時間。
2. **學生版題目**：情境、圖表／數據、問題與選項或作答要求。
3. **答案與完整推理**。
4. **選項診斷表**：每個選項的思維路徑、迷思與回饋。
5. **八準則評分表**：分數、題內證據、缺口與修訂。
6. **四項壓力測試**：捷徑、刪除、表徵必要性、課綱。
7. **資料來源與假設**。
8. **總判定**：`PASS`、`REVISE` 或 `HOLD`。

## Stop conditions

- 找不到官方父碼或真實資料來源，卻要求宣稱情境可查證。
- 物理模型需使用學生未學的關鍵理論。
- 圖表不可讀、資料矛盾或正解不唯一。
- 涉及安全、醫療或公共風險而缺可靠來源。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 有生活故事就叫素養題 | 情境資訊必須參與解題 |
| 先給自己八項 4 分 | 逐項引用證據，未過 gate 就降分 |
| 數值「看起來合理」 | 查來源或標教學用假設並做量級檢查 |
| 圖表只是裝飾 | 問題必須要求擷取或轉換圖表資訊 |
| 高層次等於多步計算 | 可用分析、評估、模型或解釋展現 |

## Example

若題目描述安全帶卻只問 $F=ma$ 的代數結果，刪除車輛情境後仍可作答，3-2 不得高於 2。應改成比較不同減速設計的量測資料，要求學生依物理證據選擇較安全方案並說明限制。
