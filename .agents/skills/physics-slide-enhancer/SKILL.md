# 物理投影片自學講稿與回饋

## Overview

讓沒有教師在場的學生仍能知道「看哪裡、想什麼、如何自我修正」。不重複投影片文字，也不以鼓勵語取代物理解釋。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/terminology/physics-terms.json`
- 涉及選項時讀取 `../../../data/misconceptions/starter.json`

## Inputs

必需：

- PPTX 或逐頁內容
- 專案學習節點碼

建議：

- 目標年級與預計每頁停留時間
- 現有 speaker notes
- 正解、解題歷程與選項設計意圖
- 影片、動畫或互動元件的實際行為

## Workflow

1. 解析官方父碼與課綱邊界。
2. 逐頁辨識教學功能、畫面焦點、學生任務與前後關係。
3. 保留有效 notes；只改寫無法自學、物理錯誤、冗長或與畫面不符者。
4. 每頁 notes 依需要包含：視覺指向、觀察問題、核心解釋、自我檢查。不要機械湊四段。
5. 轉場先回扣上一頁的未解問題，再預告下一頁的新證據或表徵。
6. 對每個選項重算正誤；錯誤回饋指出具體迷思，給一個可操作提示，不直接羞辱或只公布答案。
7. 檢查術語、符號、單位與正方向跨頁一致。
8. 檢查 notes 是否引入投影片未提供、且超出課綱或先備的內容。

## Output contract

輸出：

1. **範圍與假設**。
2. **逐頁 notes 清單**：頁碼、保留／修改／新增、講稿、轉場、預估閱讀負荷。
3. **選項回饋矩陣**：題號、選項、正誤、診斷目標、漸進提示、完整解釋。
4. **跨頁一致性問題**：術語、符號、圖片、答案與轉場。
5. **確認保留項目**與總判定。

講稿使用自然、精確的繁體中文。只有在學生需要時才加入公式朗讀方式。

## Stop conditions

- 看不到動畫／圖像卻需要描述其變化。
- 題目沒有可確認正解或條件不足。
- 投影片內容本身有物理錯誤或超綱，無法只靠 notes 修補。
- 影片時間碼或互動結果未提供，不能虛構。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 把投影片逐字念一遍 | 指向畫面、提出問題並補足推理 |
| 每頁都用「同學們請看」 | 依教學功能自然變化 |
| 答錯只說再試一次 | 指出迷思並給下一步提示 |
| 未驗算就寫正確回饋 | 先完成物理與數值檢核 |
| notes 偷渡超綱內容 | notes 也受官方父碼限制 |

## Example

對波動選項「頻率提高，波速也提高」的回饋不要只寫「錯」。寫：「先固定介質。這一頁的實驗中波速是否改變？若 $v$ 固定而 $f$ 增加，$v=f\lambda$ 要成立時，$\lambda$ 應如何改變？」
