# 物理試題品質雙檢

## Overview

以「課綱與物理」及「數值與評量」兩條獨立檢核線找出會造成誤教、誤判或無法作答的問題。先重算，再評論。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../references/stage5_curriculum_and_scope.md`
- 涉及素養題時讀取 `../../../data/rubrics/literacy-eight-criteria.json`

## Inputs

必需：

- 完整題幹、圖表、選項與標示答案
- 專案學習節點碼與課程層級

建議：

- 原始可編輯圖
- 命題意圖與預期解題歷程
- 計算工具與允許作答時間
- 已有詳解

## Workflow

1. 解析官方父碼，列出本題可合法要求的概念與深度。
2. 獨立重建模型：系統、參考系、正方向、假設、已知、未知。
3. 檢查條件充分、彼此一致、理想化是否會扭曲核心機制。
4. 獨立完成代數與數值計算；檢查單位、量綱、有效位數、極限與數量級。
5. 測試正解唯一性及每個選項是否可由合理思維路徑產生。
6. 對圖像逐一比對方向、符號、數值、比例聲明與題幹。未看到圖就不通過此項。
7. 檢查語意：否定詞、指涉、必要條件、近似、題目究竟問什麼。
8. 檢查作答負荷是否服務物理目標；繁瑣運算不是自動錯誤，但需有評量理由。
9. 提供最小修正版並再次重算，確認修正沒有產生新答案。

## Output contract

輸出：

1. **範圍卡**。
2. **獨立解題與答案**。
3. **檢核矩陣**：scope、physics、conditions、numeric、diagram、language、options。
4. **選項診斷**。
5. **缺失清單**：嚴重度、位置、原因、修正、修後答案。
6. **確認通過項目**。
7. **總判定**：`PASS`、`REVISE` 或 `HOLD`。

blocker 包含物理錯誤、正解不唯一、條件不足、官方範圍重大違反與圖文導致不同答案。

## Stop conditions

- 圖表、關鍵數據或選項缺失。
- 官方父碼無法解析。
- 題目依賴未提供的外部常數、規格或影片。
- 需要專業安全／醫療資料卻無可靠來源。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 只看詳解不獨立重算 | 從題幹重新建模 |
| 答案是整數就判數值好 | 同時檢查量級、單位與真實性 |
| 摩擦係數大於 1 就一律錯 | 看材料、模型與來源；不使用粗糙絕對閾值 |
| 看不到圖仍判一致 | 該項標 `HOLD` |
| 修題後不重算 | 每次修正都重新驗證所有選項 |

## Example

若必修 `PEb-Vc-4` 題目要求學生由 $F=ma$ 聯立多物體張力並計算，物理計算本身可能正確，但範圍仍是 major 或 blocker。審查必須同時報告「物理可解」與「不符合指定課程深度」。
