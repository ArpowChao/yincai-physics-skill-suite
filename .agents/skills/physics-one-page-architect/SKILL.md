# 一頁式物理教學架構圖

## Overview

把官方課綱邊界、九步驟與三鏈濃縮成一頁可共同備課的藍圖。架構圖用來先定義路徑，再發展投影片、學習單與素養題。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/nine-step.json`（**正向生成**：由 S1 節點選 S2 套路，設計 S8 探究，收斂 S3 原理原則，再回填 S1）
- `../../../data/big-ideas.json`
- `../../../data/rubrics/lens-selection.json`（S2 選鏡：先判結構原語，再投影到大概念）
- `../../../data/rubrics/transfer-question.json`（選配：S9 之後的跨域遷移題）

九步驟編號是知識結構的拆解順序，不是教學順序。三鏈各自錨定 S6、S8、S9；
S1 與 S2 不對學生呈現，S7 是 S5 到 S4 的轉換動作而非獨立教學站。

## Inputs

必需：

- 專案學習節點碼
- 單元名稱

建議：

- **學習階段與程度基準**（如國中會考 B 基礎、高中學測）；未提供時以單元適用年級的
  中間程度為假設並明確標示，不可略過
- 學生年級、必修／選修、節數
- 先備概念與下一單元
- 可用器材、場域與生活情境
- 既有教材或通過案例

## 開始前必須確認

在生成任何架構內容之前，先向使用者確認以下五項。**未取得答案前不生成架構**，也
**不以假設代替提問**。

1. **交付形式**：線上影片自學／現場課／混合。線上影片沒有現場教師、學生不操作
   器材，探究改由**預測型暫停點**承擔；現場課才寫分組操作、器材安全與紀錄表。
   此項不確認就設計活動，整份可能作廢。
2. **學習階段與程度基準**。
3. **先備單元**：本課排在哪些節點之後？配合 `scripts/resolve_curriculum.py` 的
   結果判定哪些術語已在別的節點教過，屬 S5 而非本課要教的 S4。
4. **節數，或影片總長與分段方式**。
5. **這節課學生最少要帶走的一句話**。這句是**深度上限**——超出它的內容一律移出
   本單元並記錄理由，不得因為完整而保留。

## Workflow

1. 解析官方父碼並摘錄課綱內容、教學說明與限制，寫出 S1 教學知識節點。
2. **先給候選，不要直接生成。** S6 體驗活動與 S9 有感應用各列 **10 個候選**，
   每個候選標註「**學生會說出的話**」與「**迷思風險**」；線上影片另加拍攝難度。
   候選一律從**學生真的碰過的東西**出發（看過、摸過、家裡有、新聞看過），
   **不得由物理概念反推類比**——由物理往下找到的情境通常物理最準，但學生沒有
   那個經驗。大概念的 2–3 個可行選項依第 3 步的方式產生，附區辨理由。三份清單
   交給使用者選擇，**未選定前不進入後續步驟**。
3. 為 S2 選教學套路：**先判結構原語，再投影到大概念**，依 `lens-selection.json`。
   不得跳過原語直接挑透鏡。
   1. **判結構原語**：這個主題的關係形狀最像哪一種——線性先後、循環、分支、
      互連網、層級、比例相等、守恆…？三族原語（圖論拓撲、動態／意象圖式、
      比例／數量）各有一張對照表。先列候選、選定本次主軸，並寫出取捨
      （選它強調什麼、犧牲什麼）。判定必須與 S6、S8 實際觀察到的關係形狀
      一致。
   2. **投影出候選透鏡**：讀原語的 `lenses` 欄，得到 2–3 個候選大概念。
   3. **只選一個**：把候選與區辨理由交給使用者，**由使用者選定一個**；生成端
      不得自行決定，也**不得在使用者未選定前往下走**。原文件允許選 1~2 個透鏡，
      本 repo 不採用。不使用主／副大概念，也不並列第二個大概念；未選中的候選
      改寫成區辨理由，其他概念只能作為分析工具。
   4. 把選定的透鏡展開成可操作的探究方式。

   七項的正式名稱包含「改變與穩定」及「結構與功能」——**「改變與穩定」是其中
   一項，不是「改變」與「穩定」兩項**；把它讀成兩項會把七項誤算成八項。原語表的
   `pole` 欄（改變／穩定）只供寫區辨理由，**不是第二個大概念**。寫進架構圖 S2 欄的
   是透鏡名，不是「環狀」「網狀」這類原語名。
4. 先標明**學習階段與程度基準**，再建立概念鏈（**錨定 S6** 體驗活動）。S6 用第 2 步
   選定的候選；優先選
   學生已有經驗的情境；若沒有，必須是短時間內容易直接觀察關鍵現象的新情境、動畫
   或模擬。離學生生活太遠且只能靠旁白理解的案例，不作主要體驗。依序形成：
   體驗 → S5 學生的一般人語言 → 經 S7 追問與測量轉換 → S4 專家的精準術語。
   此鏈不預先講出原理原則。依 `nine-step.json` 的 `S5.calibration` 檢查：學生在前一
   學習階段已取得的用詞屬 S5 不屬 S4；圖表判讀為弱項的基準，S6 需用動畫或模擬呈現。
   使用 AI 體驗影片時，片長設為 2–10 秒，只呈現一個可重播觀察的關鍵現象；把觀看
   焦點、學生語言與初步小結放在影片前後，不讓短片承擔完整背景或 S3 原理解釋。
   S5 觀察句成對寫：有變化的、沒變化的都寫（粗糙面上小車快停↔光滑面上小車
   久走），且每一對都預告一個之後活動會親眼看到的現象——
   觀察區就是活動的預告清單。學生背過但不懂的公式，也可以當起點（如以前
   背誦的 ½mv²），
   註明「以前背過」，本課任務就是把背誦變成理解。
5. 建立探究鏈（**錨定 S8** 探究活動）：用第 3 步的套路設計 → 問題 → 變因／比較 → 推理，
   重複運用專家術語進行分析、拆解、組合與比較。**線上影片交付時**，變因由影片操弄，
   學生的探究產出靠**預測型暫停點**——每一段影片至少一個，暫停前不得先講結論。
   探究問題從下方「探究活動題型庫」選型設計。
6. 由探究收斂寫出 S3 原理原則，明列適用條件；若無法在課綱內完成，先縮小範圍。
7. 由 S3 回填 S1 的內涵。S3 與 S1 不一致即需重寫，不可只改標題。
8. 建立應用鏈（**錨定 S9** 有感應用）：用第 2 步選定的候選；生活或科技問題 → 使用
   核心概念 → 決策／解釋／設計。應用從下方「應用活動題型庫」選型設計。
9. 分別列出設計順序與**教學順序**，依 `nine-step.json` 的 `generation_order` 與
   `teaching_order` 檢查；S3 不得排在 S8 之前。
10. 檢查每個節點是否在指定課程層級、能由前一節點支持、有可評量產出，且**沒有超出
    第 5 項確認的深度上限**。

### 探究活動題型庫（S8）

探究活動有七種出題方法（依 `nine-step.json` 的 `s8_inquiry_task_patterns` 選型），
不是只有控變因一式：

1. **輪流固定一個變數，最後讓數字打架**：先各自固定一個變數，最後 4×2 對 3×3
   ——乘積接近、直覺失靈，只好動手算。
2. **公式是選出來的，不是背出來的**：先讓學生提直覺答案「為什麼不是 mv」，
   再用「要能和功互換」淘汰它，選出 ½mv²。
3. **故意出一組比不出來的**：A 爐水少溫差大、C 爐水多溫差小——卡住時
   「每 1 克升 1 度」才會自己長出來。
4. **把數據畫線延伸出去**：氣體的體積—溫度直線往下延伸、交在同一點——
   絕對零度是延伸出來的，不是量出來的。
5. **做不出的實驗，就用想的＋AI 影片演出來**：無摩擦做不出來，AI 影片演
   伽利略思考實驗——思考實驗也要守控變因的紀律。
6. **反著問——怎麼做到、怎麼弄壞**：「想要超強磁場，導線怎麼繞？」——觀察
   反轉成設計目標，原理變成工具。
7. **查真實數據，還要教怎麼查**：拿台電真實發電資料當分析題——「去哪查、
   怎麼確認」直接寫進任務。

**證據來源判準**（`s8_inquiry_task_patterns.evidence_source_rule`）：判準看探究
要從畫面取得什麼，**不看是哪一個 S 步驟**。學生若要讀出**數值、比例、間距或
斜率**等可量測關係，證據必須來自實錄實驗、實測資料或有物理引擎的模擬，
**不得使用生成式 AI 影片**——畫面由模型產生、不受物理方程約束，量出來的比例
是假數據，整條由證據收斂 S3 的探究鏈會失效。結論僅為定性（哪個快、有沒有變、
往哪個方向）時才可用 AI 影片。第 5 型的伽利略思考實驗屬定性，可用；雙狹縫要
比較條紋間隔與屏幕距離、狹縫間距、波長的關係，不可用。無法實錄時改用標注參數
的物理引擎模擬；仍取不到可量測證據，就把該探究降為定性比較並寫進風險欄。

### 應用活動題型庫（S9）

應用活動有五種出題方法（依 `nine-step.json` 的 `s9_application_task_patterns` 選型）：

1. **拋真實購買問題，讓學生用規格做決定**：一句判準「看規格，不看顏色」＋
   VLT／IR／TSER 真實指標，收在連回本課原理的結論。
2. **同一件事列三種做法，讓學生評比高下**：串烤玉米列三種做法——哪種最有效？
   哪種偷用了本課原理？
3. **應用寫成回家做得到的驗證步驟**：電磁爐寫成 1. 2. 在家做得到的小驗證——
   應用升級成可檢驗的預測。
4. **四個問題一路追問，直接拿去問 AI**：設在哪→為什麼→跟我家有關嗎→
   科學上怎麼認定——整串直接當問 AI 的題目。
5. **兩個看起來一樣的現象，問異同**：拿一個學生真的看過、外觀與本課現象幾乎
   一樣的現象問「有何異同」（雙狹縫的彩色條紋 ↔ 泡泡的七彩）——相同處用本課
   原理講出來，相異處指出換了哪個機制。區辨比解釋更會逼出迷思。

S9 另守三條：

- 應用的每個例子，都用這課的新名詞講一遍——寫成完整句（安全帶＝直接作用在
  乘客身上的力，把「乘客繼續前衝」改成「跟車一起減速」），不能只列裝置名稱。
- 偷放一句下一課的內容，吊學生胃口——限一句、配白話翻譯（「同樣的速度變化，
  作用時間越長、平均受力越小（F·Δt 相同）」）。
- **遷移距離**（`s9_application_task_patterns.transfer_distance_rule`）：S9 的載體
  必須離開 S6 體驗與 S8 探究所用的器材；只換光源、換數字、換人名而器材不變的，
  是同一實驗的延伸題，不算遷移。檢查方式——把情境敘述中屬於本課器材的名詞
  刪掉，題目若就無法成立，表示還沒離開原器材。

### 活動框共同守則（S6／S8／S9）

- 比大小的題目：一個量大、另一個量小，才要動腦（小而快 vs 大而慢）——
  排不出高下，學生才會同時考慮兩個量。
- 最容易搞混的例子，直接寫進活動框備註、上課就地拆解（「拿球不動會累但
  不做功」），不是只放在作者自查清單。

### AI 影片畫面規格卡

為 S6 體驗活動、S8 探究活動、S9 應用活動各輸出一張 AI 影片畫面規格卡。三者的教學角色不可混用：

- S6：用學生熟悉或容易直接觀察的現象引發懸念，不先完成因果解釋。
- S8：讓操弄變因、控制條件、比較對象與物理證據在畫面中可辨識，供學生觀察、比較與歸納。
- S9：呈現新的應用、判斷或決策情境，迫使學生遷移已形成的原則，但不直接顯示答案。

每張卡都要具體寫出：教學角色、建議秒數（原則上 2–10 秒）、開場畫面、關鍵動作或變化、收尾畫面、鏡位與構圖、畫面中可見的物理證據、變因或比較關係、學生觀看任務、暫停或循環播放點，以及不可直接揭露的答案。描述必須具體到可直接交給影片生成工具使用，不能只寫「呈現某現象」。

若某活動不適合使用 AI 影片，仍保留該卡，寫明不使用理由、替代表徵，以及學生如何從替代表徵取得等價證據。

### 選配延伸：跨域遷移題（C2）

應用鏈完成後，詢問使用者是否在課程收尾加一題跨域遷移題：從 S3 原理原則抽出
關係形狀，找一個與其同構的他領域情境（生物、工程、地科、天文、生活），讓學生
用本單元 schema 判斷「同一關係是否還成立」。完整規則、必填欄位與常見失敗見
`transfer-question.json`。要點：

- **類比性借用，不是事實性借用**：借結構幫理解，不要求學生記住他領域數據；
  最少他領域背景 ≤2 句且直接寫進題幹。
- **保結構**：附同構說明（本單元的量與關係 ↔ 他領域的對應物）；題目考關係
  形狀是否成立，不考他領域知識。
- **負荷中低**：整合概念 ≤2、推理 ≤2 步、Aha 型收場，不得比 S8 探究更燒腦，
  也不引入新概念、不超出深度上限。
- **排在教學順序最後一站**：所需概念必須全部已教。
- **槽位不可互換**：S6 體驗的入口規則（從學生已有經驗出發，不得由物理概念
  反推類比）不變；C2 是 schema 建成後的出口遷移，兩者不得互相取代。
- **這是選配**：使用者未選用不構成缺失，審查不得因未使用而扣分。

## Output contract

輸出一份 Markdown 架構圖，包含：

- **範圍卡**：專案碼、官方父碼、課程、官方頁碼、限制、**學習階段與程度基準**。
- **兩套順序**：設計順序與教學順序分開列出。
- **核心設計**：判定的結構原語與取捨、唯一的 S2 大概念、未選相近概念的區辨理由與探究套路、S3 原理原則與適用條件、S1 節點內涵、先備與後續。
- **三鏈矩陣**：三鏈各自的錨定步驟、節點與學生產出。
- **教學流程**：依 `teaching_order` 逐站列出教學動作與學生產出。
- **Mermaid 流程圖**：節點文字精簡，設計順序與教學順序分開呈現。
- **風險與待確認**：課綱、器材、安全、來源或時間問題。
- **下一步提示**：投影片、學習單與評量各自承接哪些節點。

不要把長篇教案塞進圖中；細節放在圖後的註解。

- **AI 影片畫面規格卡**：S6、S8、S9 各一張，並依本 Skill 的固定欄位描述畫面；不使用影片時須交代理由與替代表徵。
- **跨域遷移題（選配）**：使用時依 `transfer-question.json` 的必填欄位輸出題目卡，並在教學順序中排最後一站；未選用時不輸出、不扣分。

## Stop conditions

- 官方父碼無法確認。
- 使用者給的單元名稱與官方內容明顯不一致。
- 應用情境需大量未教先用的選修或大學知識。
- 缺少關鍵教學條件，導致活動安全或可行性無法判定。

遇到上述情況，輸出 `HOLD` 與最小確認清單。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 三鏈只是同一句話換欄位 | 每條鏈要有不同功能與可觀察產出 |
| 沒標程度基準就寫 S5 學生說法 | 先定基準；同一單元不同程度的 S5 內容不同 |
| 把學生早就會用的詞當成要教的 S4 | 前一學習階段已取得的用詞屬 S5 |
| 探究問題學生用背的就能答 | 檢查既有結論會不會短路 S8，會就改寫問題 |

先給公式。應用鏈用通訊或樂器設計解釋變數關係，但不加入選修駐波推導。
