# 一頁式物理教學架構圖

## Overview

把官方課綱邊界、九步驟與三鏈濃縮成一頁可共同備課的藍圖。架構圖用來先定義路徑，再發展投影片、學習單與素養題。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/nine-step.json`
- `../../../data/big-ideas.json`

## Inputs

必需：

- 專案學習節點碼
- 單元名稱

建議：

- 學生年級、必修／選修、節數
- 先備概念與下一單元
- 可用器材、場域與生活情境
- 既有教材或通過案例

## Workflow

1. 解析官方父碼並摘錄課綱內容、教學說明與限制。
2. 用一句話寫核心理解，明列適用條件；若無法在課綱內完成，先縮小範圍。
3. 從七大概念選一個主大概念，寫出與本單元不可替代的連結。必要時才加副概念。
4. 建立概念鏈：先備 → 可觀察現象 → 模型／原理 → 表徵 → 邊界。
5. 建立探究鏈：問題 → 證據 → 變因／比較 → 推理 → 結論。
6. 建立應用鏈：生活或科技問題 → 使用核心概念 → 決策／解釋／設計。
7. 對照 S1–S9，確認三鏈合計覆蓋所有必要功能。
8. 檢查每個節點是否在指定課程層級、能由前一節點支持，且有可評量產出。

## Output contract

輸出一份 Markdown 架構圖，包含：

- **範圍卡**：專案碼、官方父碼、課程、官方頁碼、限制。
- **核心設計**：主大概念、核心理解、學習目標、先備與後續。
- **三鏈矩陣**：每階段的概念鏈、探究鏈、應用鏈及學生產出。
- **九步驟對照**：S1–S9 對應到三鏈節點。
- **Mermaid 流程圖**：節點文字精簡，標示三條鏈的交會點。
- **風險與待確認**：課綱、器材、安全、來源或時間問題。
- **下一步提示**：投影片、學習單與評量各自承接哪些節點。

不要把長篇教案塞進圖中；細節放在圖後的註解。

## Stop conditions

- 官方父碼無法確認。
- 使用者給的單元名稱與官方內容明顯不一致。
- 應用情境需大量未教先用的選修或大學知識。
- 缺少關鍵教學條件，導致活動安全或可行性無法判定。

遇到上述情況，輸出 `HOLD` 與最小確認清單。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 三鏈只是同一句話換欄位 | 每條鏈要有不同功能與可觀察產出 |
| 大概念選得越多越完整 | 選一個能統整整單元的主概念 |
| 一開始就塞公式 | 先建立現象、問題與概念需要 |
| 應用只是換人名的代算 | 要求決策、解釋或設計 |
| Mermaid 取代內容檢核 | 流程圖只呈現已驗證的設計 |

## Example

輸入 `PKa-Vc-1-1`「波速、頻率與波長」。解析為 `PKa-Vc-1` 後，概念鏈可由「同一介質中的波」走到 $v=f\lambda$ 與適用條件；探究鏈固定介質改變振源頻率並比較波長；應用鏈用通訊或樂器設計解釋變數關係，但不加入選修駐波推導。
