# 舊物理 PPT 升級

## Overview

保留老師多年累積的有效內容，只改造會阻礙自學、課綱對齊與三線一致性的部分。先審查再編輯，不以整套重做為預設。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/nine-step.json`
- 需要 notes 時使用 `physics-slide-enhancer`
- 需要圖像時使用 `physics-visual-style-guide`

## Inputs

必需：

- 原始 PPTX
- 專案學習節點碼、單元名稱與目標課程

建議：

- 因材網模板、品牌字型與既有母片
- 可修改／不可修改範圍
- 配套學習單與題目
- 預計自學時間與輸出檔名

## Workflow

1. 備份觀念上等同保留原檔：輸出新檔，不覆寫來源。
2. 解析官方父碼，抽取逐頁文字、notes、版型、圖片與互動元件。
3. 以 `physics-framework-checker` 建立保留、合併、補頁、重排、刪除清單。
4. 先修 blocker：物理錯誤、超綱、答案錯誤、缺關鍵證據。
5. 再補自學功能：目標、學生任務、notes、回饋、轉場與來源。
6. 統一術語、符號、公式與單位。不要把所有文字公式機械改成 LaTeX 圖片。
7. 套用模板時保留可讀性、替代文字與可編輯元件。
8. 產生新 PPTX 後做內容 QA、渲染 QA、notes QA 與外部連結 QA。
9. 用升級前後對照說明實際改善與仍待教師決策項目。

## Output contract

交付：

- 升級後新 PPTX，不覆蓋原始檔。
- 升級報告：官方碼、版本、保留頁、修改頁、新增頁、刪除頁。
- 九步驟前後覆蓋矩陣。
- 公式／術語／notes／互動變更清單。
- 渲染 QA 問題與修正紀錄。
- 已知限制與總判定。

如果當前工具無法安全寫入 PPTX，只交付可執行的逐頁改造規格與 Markdown 草稿，明確標示尚未完成檔案編輯。

## Stop conditions

- 原始 PPTX 損壞、受密碼保護或含無法保留的重要巨集／外掛。
- 模板或品牌資產未提供但要求完全一致。
- 只有截圖，無法可靠取得可編輯內容。
- 課綱碼、目標課程或版權許可不明。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 為統一而刪掉老師的好案例 | 先記錄強項並最小修改 |
| 直接覆寫原檔 | 新檔輸出並保留對照 |
| 只換模板就稱升級 | 同時檢查課綱、概念、自學與評量 |
| 所有公式轉圖片 | 優先保留可編輯與無障礙文字 |
| 未渲染就宣稱版面完成 | 至少一輪修正後再完整重驗 |

## Example

舊簡報若已有清楚的公車慣性現象，不要重做；保留該頁，補上學生觀察任務與轉場。若後面接大量必修不要求的公式代算，則改為定性證據與解釋，不只更換版型。
