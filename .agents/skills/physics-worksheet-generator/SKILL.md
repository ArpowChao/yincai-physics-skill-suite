# 物理學習單生成與優化

## Overview

讓學習單承接投影片中的觀察、證據、推理與遷移，而不是把投影片挖空重抄。支援 WSQ 與三層模式，先依教學用途選模式。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/nine-step.json`
- `../../../references/worksheets_templates_and_examples.md`

## Inputs

必需：

- 投影片、逐頁文字或既有學習單
- 專案學習節點碼
- 指定模式；未指定時依用途選擇並說明

建議：

- 教學時間、個人／小組、可用器材
- 學生先備與特殊需求
- 預期輸出 Markdown 或 DOCX
- 答案版需求

模式：

- **WSQ**：課前觀看、自我摘要、帶問題進課堂。
- **三層**：預習觀察、課中數據與討論、課後遷移。

## Workflow

1. 解析官方父碼，整理投影片的目標、核心概念、證據、活動與應用。
2. 選模式並列出學習單與投影片的分工；避免重複所有內容。
3. 建立題目藍圖：每題對應目標、九步驟、認知層次、預期證據與估時。
4. WSQ 的 W 要指定觀看焦點；S 要讓學生組織證據；Q 要提供可選的提問鷹架。
5. 三層模式讓預習形成可帶入課堂的猜想，課中留下數據與論證，課後要求新情境遷移。
6. 數據表只在真的有數據時加入；欄名、單位、有效位數與變因要清楚。
7. 產生學生版與答案／教師提示版；答案不能出現在學生作答區。
8. 若輸出 DOCX，套用既有模板並完成渲染檢查；不要宣稱 Word 排版完成而未渲染。

## Output contract

輸出包含：

- **設計摘要**：模式、官方父碼、目標、時間、與投影片分工。
- **題目藍圖表**。
- **學生版完整內容**。
- **教師版答案、評分重點與常見迷思**。
- **無障礙與版面檢查**：字級、留白、表格寬度、圖片替代文字、黑白列印。
- **確認保留項目、缺失與總判定**。

若使用者要求 DOCX，最終交付 DOCX 與同內容 Markdown；先驗證檔案與渲染頁面。

## Stop conditions

- 投影片目標或官方父碼無法確認。
- 要求虛構影片時間碼、實驗數據或學生答案。
- 活動需要未知器材、安全條件或無法在時限內完成。
- DOCX 模板缺失且使用者要求完全沿用既有版型。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| 每份學習單都強塞數據表 | 只有證據任務需要時才加入 |
| WSQ 的 S 只是抄定義 | 要求學生用證據組織概念 |
| Q 只留「我沒有問題」 | 提供澄清、深化、應用提問句型 |
| 課後單只是更多同型計算 | 改為新情境遷移或解釋 |
| 只產學生版 | 同步提供答案與診斷提示 |

## Example

對 `PEb-Vc-4-1` 牛頓第一定律，預習單可讓學生記錄公車啟動／煞車時的身體感受；課中單比較小車在不同表面的滑行證據；課後單要求解釋安全帶如何提供改變運動狀態的外力，不要求必修學生做運動方程式代算。
