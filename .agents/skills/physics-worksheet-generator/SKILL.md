# 物理學習單生成與優化

## Overview

讓學習單承接投影片中的觀察、證據、推理與遷移，而不是把投影片挖空重抄。支援 WSQ 與三層模式，先依教學用途選模式。

開始前讀取：

- `../../../references/skill-runtime.md`
- `../../../data/rubrics/nine-step.json`（**正向生成**：預習承接 S6、課中承接 S8、課後承接 S9）
- `../../../references/worksheets_templates_and_examples.md`

## Inputs

必需：

- 投影片、逐頁文字或既有學習單
- 專案學習節點碼
- 指定模式；未指定時依用途選擇並說明

建議：

- 教學時間、個人／小組、可用器材
- 學生先備與特殊需求
- 預期輸出 Markdown 或 DOCX
- 答案版需求

模式：

- **WSQ**：學生邊看影片／簡報邊寫的一頁紀錄單：記下重點、用一句話寫出核心觀念、留下一個想法。重點是短，看完影片後 10 分鐘內寫完。
- **三層**：預習觀察、課中數據與討論、課後遷移。

### WSQ 固定格式

格式固定，不增減區塊：

| 區 | 學生做什麼 | 數量 | 上限 |
|---|---|---|---|
| W 看影片，記重點 | 依影片順序填關鍵詞或勾選 | 3～5 格 | 每格標投影片頁碼「（第 N 張）」，題目 35 字內 |
| S 寫出重點觀念 | 用自己的話寫一句 | 1 題 | 30 字內，附句首提示 |
| Q 留下一個想法 | 三個句首選一個寫 | 1 題 | 一行 |

全份 5～7 格、一頁 A4、作答 10 分鐘內。學生版不放數據表、公式推導、計算題、影片時間碼，也不要求三種提問都寫；這些留給三層的課中單或課堂討論。

## Workflow

1. 解析官方父碼，整理投影片的目標、核心概念、證據、活動與應用。
2. 選模式並列出學習單與投影片的分工；避免重複所有內容。
3. **WSQ**：
   1. 從簡報挑 3～5 個學生看完一定要記住的重點（關鍵現象、概念名稱、結論），依影片順序排列，每格標投影片頁碼。不要每張投影片都出一格。
   2. 每格只留一個空格或一組二選一勾選，學生看到那一張就能寫。
   3. S 寫出本節核心觀念的句首提示，通常取自總結頁；學生補完成一句話。
   4. Q 固定三個句首：「我還不懂……」「我想知道如果……會怎樣？」「這讓我想到生活中……」，學生選一個寫。
   5. 執行 `python scripts/audit_wsq.py <WSQ.md>`，處理所有 ⚠。超過上限就刪格，不是縮小字級。
   6. 執行 `python scripts/build_wsq_docx.py <WSQ.md> outputs/<節點編號>_<單元名稱>_WSQ.docx` 產生 DOCX，轉 PDF 確認只有一頁。
4. **三層**：建立題目藍圖，每題對應目標、九步驟、認知層次、預期證據與估時。預習形成可帶入課堂的猜想，課中留下數據與論證，課後要求新情境遷移。
5. 數據表只在三層模式真的有數據時加入；欄名、單位、有效位數與變因要清楚。
6. 三層模式產生學生版與答案／教師提示版；答案不能出現在學生作答區。WSQ 不產教師版。
7. 三層模式若輸出 DOCX，套用既有模板並完成渲染檢查；不要宣稱 Word 排版完成而未渲染。

## Output contract

WSQ 輸出：

- **DOCX**：只有學生版，依「WSQ 固定格式」，一頁 A4；中文微軟正黑體、英文與數字 Arial。
  版型由 `build_wsq_docx.py` 固定產生，不手動改排版：米色標題區加深藍「WSQ」標籤、
  W／S／Q 色塊徽章（藍／橘紅／綠）、W 每格的「第 N 張」頁碼標籤、S 與 Q 的淡色作答框；
  黑白列印時仍分得出三區與作答線。
- **同內容 Markdown**：DOCX 由它產生，也是 `audit_wsq.py` 的檢查對象。
- 回報時附一行說明（節點碼、對應投影片範圍、預估作答時間）與 `audit_wsq.py` 結果。不產教師版。

三層輸出：

- **設計摘要**：模式、官方父碼、目標、時間、與投影片分工。
- **題目藍圖表**。
- **學生版完整內容**。
- **教師版答案、評分重點與常見迷思**。
- **無障礙與版面檢查**：字級、留白、表格寬度、圖片替代文字、黑白列印。
- **確認保留項目、缺失與總判定**。

若使用者要求 DOCX，最終交付 DOCX 與同內容 Markdown；先驗證檔案與渲染頁面。

## Stop conditions

- 投影片目標或官方父碼無法確認。
- 要求虛構影片時間碼、實驗數據或學生答案。
- 活動需要未知器材、安全條件或無法在時限內完成。
- DOCX 模板缺失且使用者要求完全沿用既有版型。

## Common mistakes

| 錯誤 | 修正 |
|---|---|
| WSQ 每張投影片都出一格 | 只挑 3～5 個看完一定要記住的重點 |
| WSQ 放數據表、公式推導或計算 | WSQ 只記錄與歸納；這些留給三層的課中單 |
| WSQ 用影片時間碼定位 | 標投影片頁碼；時間碼會隨剪輯改變，也容易虛構 |
| WSQ 的 S 只是抄定義 | 給句首提示，要學生用自己的話寫一句 |
| Q 三種提問都要寫，或只留「我沒有問題」 | 給三個句首，選一個寫 |
| 每份學習單都強塞數據表 | 只有三層的證據任務需要時才加入 |
| 課後單只是更多同型計算 | 改為新情境遷移或解釋 |
| 三層只產學生版 | 同步提供答案與診斷提示（WSQ 例外，只產學生版） |
| WSQ 另寫教師版或答案頁 | WSQ 只交學生版 DOCX |

## Example

對 `PEb-Vc-4-1` 牛頓第一定律：

- **WSQ**：W 四格，依序記公車煞車時身體往哪傾、表面愈光滑滑行愈遠、沒有外力時的運動、慣性一詞；S 補完「物體不受外力時，……」；Q 選一個句首寫。完整範例見 `references/worksheets_templates_and_examples.md`。
- **三層**：預習單讓學生記錄公車啟動／煞車時的身體感受；課中單比較小車在不同表面的滑行證據；課後單要求解釋安全帶如何提供改變運動狀態的外力，不要求必修學生做運動方程式代算。
