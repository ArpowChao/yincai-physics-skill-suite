# PEb-Vc-4-1 素養題示範：校車安全宣導

## 命題藍圖

- 官方父碼：`PEb-Vc-4`
- 評量主張：學生能根據煞車過程的觀察紀錄，判斷安全帶如何改變乘客的運動狀態。
- 認知歷程：擷取表格資訊、比較解釋、用第一定律評估宣導文字。
- 題型：四選一，建議 3 分鐘。
- 邊界：定性理解，不使用運動方程式或公式計算。

## 學生版

某校準備製作校車安全海報。設計小組用假人模擬校車直線行駛後煞車，記錄如下：

| 階段 | 校車狀態 | 假人相對車內的現象 | 安全帶狀態 |
|---|---|---|---|
| 甲 | 等速直線行駛 | 假人保持坐姿 | 尚未明顯拉緊 |
| 乙 | 開始減速 | 假人上半身相對車廂向前 | 開始拉緊 |
| 丙 | 繼續減速 | 假人隨車減速 | 對假人施力 |

根據紀錄與牛頓第一定律，下列哪一句最適合放在海報上？

A. 煞車時安全帶會消除乘客原本向前的力，所以乘客停止前進。

B. 乘客受到一個稱為「慣性力」的向前推力，安全帶用反方向的力把它抵消。

C. 乘客原本和車一起向前運動；安全帶對乘客施力，使乘客的運動狀態能隨車改變。

D. 安全帶使乘客的質量暫時變小，所以煞車時比較容易停下來。

## 答案與完整推理

正解：**C**

1. 甲階段顯示乘客原本與校車一起向前等速運動。
2. 校車先減速時，假人上半身仍傾向維持原來的向前運動狀態，因此相對車廂向前。
3. 丙階段安全帶拉緊並對假人施力，這個外力使假人的速度跟著改變。
4. 安全帶不是消除慣性或改變質量，也不必把慣性當成真實向前作用的力。

## 選項診斷與回饋

| 選項 | 診斷目標 | 回饋 |
|---|---|---|
| A | 認為運動必須由同方向力維持 | 先看甲階段：安全帶尚未拉緊時，假人仍和車一起等速運動。維持運動不需要持續的向前合力。 |
| B | 把慣性當成作用在物體上的力 | 慣性是物體維持運動狀態的性質，不是另一個物體施加的向前力。請找出丙階段真正接觸假人的物體。 |
| C | 正確 | 你同時使用了甲的原運動狀態、乙的相對前傾及丙的安全帶施力。 |
| D | 認為安全裝置會改變質量／慣性 | 安全帶改變的是乘客受到的力與速度，不會讓乘客的質量暫時變小。 |
