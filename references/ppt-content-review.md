# 因材網高中物理內容型 PPT 總審查規準

本規準補充九步驟架構檢核，判斷內容型簡報是否真的形成學生可理解、可作答、
可得到回饋並能遷移的教學路徑。九步驟回答「功能是否覆蓋」；本規準回答
「這些功能是否連得起來、內容是否足以教會學生」。

## 1. 中央教學任務

先用一句話描述：

> 學完後，學生應能以【核心原理】對【新情境】做出【可觀察表現】，
> 因為課程提供了【關鍵證據與推理】。

本專案以單元名稱作為學習目標錨點，不要求另外出現「學生能夠……」式目標頁。
審查重點是內容、活動、例題與評量是否都對準單元名稱；若偏離才列缺失。

大概念也不要求在投影片上明列。應從跨頁活動、問題、證據、原理與應用反推
一個統整觀念，並標示為「推定大概念」。只有無法合理反推、不同活動彼此矛盾，
或應用沒有使用該觀念時，才判定不足。課名能作為目標錨點，但不能單獨證明
內容對齊；仍須用逐頁證據檢查。

若無法從整份簡報寫出唯一且合理的中央教學任務，才判定中央主線不清。

建議的大弧線是：

`值得追問的現象 → 可共享的觀察或資料 → 比較與推理 → 概念與精準術語 →
原理及條件 → 練習及回饋 → 新情境應用 → 回答開場問題`

順序可以調整，但每次跳躍都要有教學理由。

## 2. 逐頁教學清冊

每頁指定一個主要角色。若同頁承擔太多角色，檢查認知負荷與揭露順序。

- `orientation`：目標／定向
- `engage`：引發／體驗
- `evidence`：觀察／證據
- `inquiry`：探究／推理
- `concept`：概念形成
- `precision`：術語、符號、公式與適用條件
- `representation`：文字、圖、表、向量、公式或模型的表徵轉換
- `example`：示例／反例
- `check`：檢核／回饋
- `transfer`：遷移／應用
- `synthesis`：統整／收束
- `transition`：必要的頁間橋接
- `decoration`：裝飾或章節標籤，不計為教學功能

逐頁清冊至少記錄：

| 欄位 | 判讀問題 |
|---|---|
| `teaching_role` | 本頁唯一主要教學角色是什麼？ |
| `primary_question` | 本頁要回答的問題或建立的主張是什麼？ |
| `learner_action` | 學生要看、說、寫、算、選、畫或比較什麼？ |
| `expected_output` | 可觀察、可判定的學生產出是什麼？ |
| `feedback` | 學生如何知道答案對錯及錯在哪裡？ |
| `prerequisite` | 本頁需要哪些先備，前面是否建立？ |
| `next_link` | 本頁產出如何被下一頁使用？ |
| `architecture_elements` | 對應 S1–S9 哪些功能？ |
| `continuity_tags` | 是否有連貫性斷點？ |

圖片、影片、活動、計算與提問本身不等於學生思考證據；必須指出學生輸出與回饋。

## 3. 四層審查

### A. 架構覆蓋

把架構承諾對到實際頁碼，標示 `complete`、`partial`、`insufficient`、
`contradicted` 或 `N/A`。不能只找相同名詞，要確認學生行為與推理真的被實現。

S1 接受單元名稱作為學習目標錨點，判斷內容是否對題；不要因缺少行為動詞式
目標句扣分。S2 由活動與應用反推大概念；不要因缺少「大概念」標題或專頁扣分。

若另外提供一頁式架構 PPT，再列出「架構未承諾但內容新增」的支線，判斷是必要
補強或離題。若沒有架構檔，「架構覆蓋」標為 `N/A`，不得因缺檔給 0 分。

### B. 連貫性

逐頁回答：

1. 這頁需要哪些先備？前面已建立嗎？
2. 這頁回答上一頁哪個問題，或使用哪項證據？
3. 這頁新增什麼理解，而不是只重複？
4. 這頁為下一頁創造什麼需要？
5. 刪除此頁，推理鏈會不會中斷？

同時追蹤問題線、證據線、變因線、語言線與表徵線。

### C. 內容充實度

每個核心概念應依需要包含：

1. 學生能理解的問題或現象。
2. 可觀察或可分析的證據。
3. 從證據到結論的可見推理。
4. 正式概念、術語、公式及適用條件。
5. 容易混淆的反例、邊界或迷思澄清。
6. 答案不會過早揭露的示範或引導練習。
7. 能取得學生輸出的檢核。
8. 解釋正確理由與典型錯誤原因的回饋。
9. 使用同一核心原理的新情境遷移。
10. 回應開場問題的統整。

頁數多、範例多或文字長不代表充實；功能重複而沒有提高認知要求仍屬薄弱。

### D. 教學可用性

- 任務有清楚輸出格式、判準、答案及解釋。
- 答案與提示在適當時機出現，不搶走學生思考。
- speaker notes 補足觀看焦點、推理與轉場，且沒有其他單元殘留。
- 內容密度、數學跨度與先備知識適合指定學生。
- 圖像、動畫或影片提供可觀察資訊，而不只是吸睛。
- 學生每個階段都知道下一步要做什麼。

若整份課程只要求觀看、不取得任何學生輸出，「教學可用性」最高 1 分。

## 4. 連貫性斷點標籤

- `JUMP`：直接進入結論、公式或新主題，沒有鋪墊。
- `UNRESOLVED`：問題、預測或例題沒有後續答案與理由。
- `PREMATURE`：術語、公式或微觀機制早於可理解的證據。
- `DRIFT`：情境需要大量單元外知識，主線被帶離。
- `REPEAT`：內容重複但未提高認知要求。
- `CONTRADICTION`：頁面、講稿、答案、圖或公式彼此衝突。
- `MISSING-BRIDGE`：兩頁各自正確，但缺少觀察到概念的推理。
- `MISSING-FEEDBACK`：有作答，沒有判準或錯誤原因。
- `DEAD-END`：活動沒有產生後續要使用的證據或概念。
- `UNUSED-CONCEPT`：教過的術語或公式未在後續任務使用。

## 5. 物理、題目、活動與媒體

### 物理與題目

- 檢查物理量定義、純量／向量、符號、單位、正負號與座標方向。
- 區分觀察、模型、推論與定律；生成動畫不是直接觀察證據。
- 寫出介質、系統邊界、參考系、摩擦、穩態、封閉性與近似條件。
- 重新計算所有關鍵數值，確認條件足以得到唯一答案。
- 可見選項、講稿、動畫揭露與答案頁必須一致。
- 錯誤選項應對應可辨認迷思，回饋要說明錯誤原因。

### 探究與安全

- 標示自變因、依變因、控制變因、量測方式、重複次數與比較基準。
- 資料必須能區分題目中的不同解釋。
- 將觀察、資料整理、推理與結論分開。
- 檢查熱源、高溫液體、電力、雷射、紫外線、拋射物、道路與人體示範安全。

### 圖像、動畫與影片

每段媒體記錄：

- `role`：情境、觀察、證據、探究操作、應用或裝飾。
- `observation_focus`：學生要看什麼。
- `pause_points`：何時停下比較或作答。
- `comparison`：比較哪些量，控制哪些條件。
- `learner_output`：看完要說、寫、算、選或畫什麼。
- `used_later`：該輸出在哪一頁被後續推理使用。

另檢查時間順序、方向、尺度、守恆、儀表數值與因果連續。媒體如果沒有產生後續
推理所需的證據，只能算情境素材；若戲劇性、人物或旁支資訊比觀察焦點更突出，
標示 `DRIFT` 或分心風險。生成畫面不得作為未另行提供的定量資料。

## 6. 評分與 critical gates

十項各評 0–3 分：

1. 中央目標與主線
2. 架構覆蓋
3. 順序與轉場
4. 證據—推理—原理
5. 語言與表徵橋接
6. 解釋深度與適用條件
7. 學生任務與輸出
8. 檢核與回饋
9. 遷移與收束
10. 教學可用性與講稿

`0` 為缺漏、錯誤或矛盾；`1` 為形式存在但功能薄弱；`2` 為基本完整但仍有
斷點；`3` 為證據充分且可直接使用。分數不能抵銷 critical gate。

「中央目標與主線」評分以單元名稱和實際內容的一致性為主，不以是否另列目標句
為判準。「架構覆蓋」中的大概念允許由活動反推，報告中要列出推定內容及頁碼證據。

下列任一項成立，整體不得 `PASS`：

- 核心物理敘述或公式條件錯誤。
- 架構的核心原理缺漏、矛盾或被另一模型取代。
- 正解、選項、圖、公式與講稿互相衝突。
- 危險活動沒有風險控制。
- 應用無法由課程所教內容完成，或答案違反核心原理。
- 關鍵學生任務完全沒有可判定輸出或回饋。

## 7. 審查輸出

先給 `PASS`、`REVISE` 或 `HOLD`，再提供：

1. 檢查範圍、最強段落與最大缺口。
2. 目前教學路徑與建議路徑。
3. 最多五項最高優先修正。
4. 架構—內容對照與十項評分。
5. 逐頁教學清冊及斷點標籤。
6. 缺漏內容與最小修復藍圖。
7. 物理、媒體、實驗安全與版面風險。
8. 已確認應保留的優點。
9. 會改變結論的判讀限制。

每項 finding 引用頁碼和可見文字／物件。區分 `missing`、`thin`、
`out_of_sequence`、`contradicted` 與 `not_observable`。先檢查能否移動、合併、
縮短或重寫現有內容，必要時才建議新增投影片。
