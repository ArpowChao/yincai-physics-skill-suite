# 第五學習階段高中物理課綱與防超綱指南

本文件是人類可讀的操作摘要。完整 120 筆普高必修 `Vc` 與加深加廣選修 `Va`
條目、課綱陳述、教學說明及 PDF 頁碼位於
`data/curriculum/stage5-physics.json`；技高物理 A／B、選修物理 1–4 與 SDGs
教材的專案節點映射位於 `data/curriculum/project-node-catalog.json`。

## 先區分兩種代碼

- `PEb-Vc-4`、`PKa-Va-13`：官方學習內容碼。
- `PEb-Vc-4-1`、`PKa-Va-13-2`：本專案為教材拆分建立的學習節點碼。
- `PBa-V.1-2-2`：技高物理 A／B 使用的專案節點碼；其父層、課程版本與官方
  頁碼必須由專案節點目錄精確查得，不可套用普高代碼切割規則猜測。

審查時先做專案節點的完全相符查詢，再解析普高專案碼的最長官方父碼。不可因
檔名多了數字段，就宣稱課綱也有該條目；技高節點查無完全相符資料時也不可猜測。

```powershell
python scripts/resolve_curriculum.py PEb-Vc-4-1
python scripts/resolve_curriculum.py PBa-V.1-2-2
```

`PBa-V.1-2-2 動能` 的核定映射是技高物理 A 的
`PBa-V.1-2 能與力的關係`（官方課綱第 108 頁）。節點表的舊參照欄卻標成
`PBa-Vc-2-2 位能的定義`，因此目錄保留
`mapped-with-source-conflict`：可確認官方父層與單元名稱，但不得用錯置的舊碼
擴張公式計算或功能定理推導深度。

## 必修與選修不是「能不能出現公式」的二分法

範圍判定必須看每一條官方「學習內容說明」，不能只用 `Vc = 不計算`、`Va = 可微積分` 之類口訣。例：

| 官方碼 | 官方內容與說明摘要 | 審查重點 |
|---|---|---|
| `PEb-Vc-4` | 牛頓三大運動定律；課綱說明以定律意義為主，不涉及公式推導與計算 | 必修教材若要求以運動方程式做定量推導，應標重大範圍風險 |
| `PKa-Vc-1` | 波速、頻率、波長的數學關係；可說明數學式，但不推導公式 | 可使用關係式，不代表可加入選修波動的完整數學推導 |
| `PKa-Vc-4` | 反射與折射；說明可用圖示定量處理司乃耳定律 | 不能用「必修一律不得定量」誤殺合法內容 |
| `PKc-Vc-3` | 變動磁場產生電場、變動電場產生磁場；定性介紹法拉第感應 | 不得直接要求選修層級的磁通量變化率計算 |
| `PEb-Va-15` | 可用牛頓定律解釋或計算靜力平衡、摩擦與一維碰撞 | 仍須遵守該選修課程的教學說明與合理計算負荷 |
| `PKc-Va-10` | 法拉第定律的定量表述 | 可做選修層級定量，但不代表大學電磁學內容自動合格 |

上述依據官方課綱 PDF 第 38–40、186–202 頁。實際審查請引用 JSON 條目的頁碼，不要只引用本摘要。

## 防超綱流程

1. 取得使用者指定的專案碼、學生年級、必修或選修課程。
2. 先精確查詢專案節點映射，再解析官方父碼；兩者皆失敗即 `HOLD`。
3. 讀取該碼的 `statement` 與 `teaching_note`。
4. 列出教材要求學生實際完成的概念、數學工具、推導與實驗。
5. 逐項比對官方說明，而不是只掃描關鍵字。
6. 將結果分成：
   - `PASS`：有官方依據且要求不超過說明。
   - `REVISE`：內容可保留，但深度、活動或評量要求需降低／調整。
   - `HOLD`：代碼、證據或課程層級不足，必須人工確認。

## 常見誤判

- 教材出現進階名詞不一定等於學生必須操作該理論；應檢查它是背景介紹還是評量要求。
- 公式出現不一定超綱；反之，沒有公式也可能用文字要求超綱推理。
- `美工(已)` 代表歷史製作狀態，不代表符合新版九步驟或現行課綱審查。
- LLM-wiki 可能含大學物理內容；不能因內容正確就判定適合第五學習階段。
- 專案節點名稱與舊參照碼衝突時，不可用舊碼覆蓋節點名稱或官方父層；只把受
  衝突影響的範圍判定列為 `HOLD`，並明列需要人工裁決的欄位。
